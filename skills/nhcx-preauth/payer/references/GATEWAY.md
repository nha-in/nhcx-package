# Gateway

Every part of the NHCX gateway, in one list. Each row links to its full spec in [../gateway/](../gateway/INDEX.md). The gateway runs inside the application process: the application calls it as functions, and the only HTTP it serves is the inbound route NHCX posts to and the health checks. It is the only code that talks to NHCX and the ABDM registry.

| # | Part | Entry | What it does | Used by |
|---|---|---|---|---|

| [G11](../gateway/G11-startup-checks.md) | Startup Checks and Health | `gateway.check`, `/healthz`, `/readyz` | Checks the token, the registry record, that the registered certificate matches the private key, and that the registered endpoint reaches this application; answers liveness and readiness.
